# Installation options:
#
# 1. Install everything:
#    pip install -r requirements-all-providers.txt
#
# 2. Install specific providers only:
#    pip install openai anthropic  # Just OpenAI + Claude
#
# 3. Install local inference only:
#    pip install huggingface-hub transformers
#    # Then install Ollama separately: curl -fsSL https://ollama.com/install.sh | sh
#
# 4. Install enterprise only:
#    pip install openai boto3 google-cloud-aiplatform
#
# 5. Install fast inference only:
#    pip install groq together replicate
#
# Provider-specific setup:
#
# - Ollama: Install from https://ollama.com/
# - LM Studio: Download from https://lmstudio.ai/
# - vLLM: Requires CUDA for GPU support
# - AWS Bedrock: Requires AWS credentials configured
# - Vertex AI: Requires GCP credentials configured
# - Azure OpenAI: Requires Azure subscription
#
# GPU requirements (for local models):
# - Small models (7B-13B): 8-16 GB VRAM
# - Medium models (30B-40B): 24-32 GB VRAM
# - Large models (70B+): 48-80 GB VRAM or CPU with 64GB+ RAM
