┌─ WHAT HAPPENS DURING THE DEMO ────────────────────────────────────────────────────────┐
│                                                                                        │
│  PHASE 1: System Registration (0.3s)                                                  │
│  ├─ Registers autonomous agent orchestration engine                                   │
│  ├─ Calculates baseline health metrics                                                │
│  └─ Enables monitoring and alerting                                                   │
│                                                                                        │
│  PHASE 2: Anomaly Detection (0.8s)                                                    │
│  ├─ Real-time error detection triggered                                              │
│  ├─ Error classification: CRITICAL - Process Crash                                    │
│  ├─ Root cause analysis performed                                                     │
│  └─ Metrics snapshot captured (CPU, Memory, Response Time, etc.)                      │
│                                                                                        │
│  PHASE 3: Correction Strategy Selection (2.1s)                                        │
│  ├─ Query policy database                                                             │
│  ├─ Evaluate 12 candidate correction strategies                                       │
│  ├─ Select optimal strategy: Graceful Restart (98.5% confidence)                      │
│  ├─ Pre-correction safety checks (dry-run, locks, consistency)                        │
│  └─ Execute correction asynchronously                                                 │
│                                                                                        │
│  PHASE 4: Recovery Monitoring (3.7s)                                                  │
│  ├─ 12-stage recovery execution with real-time progress                               │
│  ├─ Graceful shutdown → Process termination → State cleanup                           │
│  ├─ Service restart → Health checks → Pool warmup                                     │
│  └─ Verify all endpoints responsive and requests flowing                              │
│                                                                                        │
│  PHASE 5: Health Verification (1.1s)                                                  │
│  ├─ Collect post-recovery metrics                                                     │
│  ├─ Compare with baseline (Health Score: 95 → 98.7)                                   │
│  ├─ Validate data consistency across replicas                                         │
│  └─ Re-enable alerts and monitoring                                                   │
│                                                                                        │
│  PHASE 6: Audit Logging (included above)                                              │
│  ├─ System registration logged                                                        │
│  ├─ Error detection and classification logged                                         │
│  ├─ Policy evaluation and strategy selection logged                                   │
│  ├─ Pre-checks and correction execution logged                                        │
│  └─ Recovery stages and verification logged                                           │
│                                                                                        │
│  TOTAL TIME: ~10 seconds                                                              │
│                                                                                        │

┌─ API ENDPOINTS DEMONSTRATED ──────────────────────────────────────────────────────────┐

│  1. POST /api/v1/systems                                                              │
│     └─ Registers a system for monitoring                                             │

│     └─ Records detected errors with context                                          │

│  4. POST /api/v1/corrections                                                          │
│     └─ Executes autonomous correction actions                                        │
│                                                                                        │
│  5. GET /api/v1/corrections/system/{id}/recent                                        │
│     └─ Retrieves correction history                                                  │
│                                                                                        │
│  6. GET /api/v1/corrections/statistics/summary                                        │
│     └─ Shows correction statistics and success rate                                  │
